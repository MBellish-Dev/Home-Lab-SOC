SOC Investigations

This directory contains documented investigations performed using the home lab's security monitoring environment.

Each investigation focuses on the analyst perspective.

Investigation Process
Alert / Event
     ↓
Initial Triage
     ↓
Evidence Collection
     ↓
Timeline
     ↓
Analysis
     ↓
Findings
     ↓
Response
     ↓
Lessons Learned

Investigation Standards
- Each investigation should document:
  - What happened
  - When it happened
  - Affected system
  - Source of activity
  - Relevant evidence
  - Timeline
  - Analysis
  - Findings
  - Response
  - Detection gaps

Lessons learned
- Investigations should use sanitized information and must not expose credentials or sensitive personal/network information.
